# Requisitos del sistema
## Requerimientos Funcionales
RF-01. El sistema permitira registrar asistentes al congreso

RF-02. El sistema permitira consultar las actividades disponibles

RF-03. El sistema permitira registrar un asistente a una actividad

RF-04. El sistema permitira cancelar el registro de un asistente a una actividad

RF-05. El sistema permitira registrar ponentes del congreso

## Requerimientos No Funcionales
RNF-01. La interfaz debera ser accesible desde un navegador web

RNF-02. El sistema debera mantener la informacion de registro de manera persistente

RNF-03- Se actualice la base de datos
